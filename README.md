# BP Franchise Inventory & Operations Management System

A backend inventory and operations management system designed for a
single-location gas station convenience store.

## Planned Technology Stack

- C#
- ASP.NET Core Web API
- SQL Server
- Entity Framework Core
- ASP.NET Core Identity / JWT
- Azure

## Current Status

- Business discovery and MVP scoping complete
- ASP.NET Core project initialized
- Git/GitHub repository initialized

## Planned Core Features

- Product management
- Category management
- Vendor management
- Inventory tracking
- Restock events
- Inventory adjustments
- Low-stock reporting
- Users and roles
- Audit logging
